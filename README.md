# TP Binge Remake

A static remake of the TP Binge channel listing UI. It includes responsive channel cards, category filters, search, favorites, and a dark-mode toggle.

## Run Locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Deploy

This project is ready for GitHub Pages because it has no build step. Publish the folder to a GitHub repository and enable Pages from the repository settings.
